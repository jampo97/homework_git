# Проект - homework

## Проект представляет собой работу с Git и включает в себя выполненные работы по урокам 9.2, 10.1, 10.2, 11.1, 12.1

## Модуль widget.py 
- маскирует введенные данные
- форматирует дату в формат ДД.ММ.ГГГГ

## Модуль masks.py 
- маскирует номер счета
- маскирует номер карты

## Модуль processing.py 
- фильтр данных по состоянию
- сортировка данных по дате

## Модуль generators.py 
- фильтр транзакций по валюте
- формирует список названий всех транзакций

## Модуль decorators.py 
- декоратор логов

## Модуль utils.py 
- возвращает список словарей с данными о финансовых транзакциях

## Модуль external_api.py 
- Конвертер валюты в рубли через API
